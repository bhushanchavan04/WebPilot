Features

not a chatbot. a copilot for the open web.

01

Page Understanding

Automatically reads the full DOM of any site you visit — product pages, dashboards, articles, forms — and converts it into a rich context window the AI truly understands.

02

Contextual Highlighting

Ask the agent to find, highlight, or explain any element on the page. It pinpoints exactly what you're looking for with zero copy-paste.

03

Page Actions

Goes beyond answers. The agent can click buttons, fill forms, and navigate for you — like a second pair of hands that never gets tired.

04

Multi-Site Memory

Maintains context across tabs so you can compare products, cross-reference articles, and continue conversations without repeating yourself.

05

Webchat

Works on any web chat, support portal, or messaging surface. Compose replies, summarise threads, and draft responses in your own voice.

06

Local Models

Plug in your own Ollama instance and run everything 100% locally. Your conversations never leave your machine unless you want them to.

07

Knowledge Base

Save pages, snippets, and notes into a personal knowledge base the agent can query. Build your own second brain, one tab at a time.

08

Workflow Macros

Record multi-step interactions and replay them with a single command. Stop re-doing the same tedious flows across every browser session.

Setup

four steps. no store required.

Install in developer mode — takes under two minutes. You keep full control: no telemetry, no mandatory sign-up, no extensions store approval cycle.

How to load an unpacked extension ↗

01
Download & unzip

Click the download button and extract the zip file anywhere on your machine.

02
Open Extension Manager & enable developer mode

Go to chrome://extensions, toggle on Developer mode in the top right.

03
Load unpacked

Click Load unpacked and select the extracted folder.

04
Pin & open settings

Pin the extension, open the popup, enter your API key for any provider and you're live.
